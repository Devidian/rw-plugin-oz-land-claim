## Stable claim-information overlay

- The upper claim-information overlay now refreshes immediately after player
  connect, spawn, and chunk transitions.
- Visibility changes and text updates are idempotent, avoiding unnecessary
  remove/add cycles while the overlay stays visible.
- A refresh failure for one player no longer interrupts updates for other
  players, and repeated failures are rate-limited until recovery.

This release does not change the Land Claim database, configuration format, or
public integration APIs.
