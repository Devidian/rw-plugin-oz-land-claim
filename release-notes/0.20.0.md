# OZ Land Claim 0.20.0

- Administrators can manage renew zones individually or in bulk without losing
  scheduled due timestamps when the scheduler is disabled.
- Player-owned and unclaimed claims support optional rental purchase with
  persistent daily settlement, tenant and landlord permissions, and safe
  eviction when a payment fails.
- Administrative claim removal now follows the same automatic-cleanup safety
  path as inactive-claim cleanup.

Requires OZ Tools 0.25.0.
